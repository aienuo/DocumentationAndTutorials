## 双网卡配置 ##

> 同时满足“上网”和“自定义 IP”的需求，最直接的方案是为虚拟机添加**两块网卡**：一块用于连接互联网（NAT 模式），另一块用于自定义内部网络（仅主机模式或自定义模式）。

### 核心方案：双网卡配置 ###

让两块网卡各司其职，互不干扰：
*   **网卡一（NAT 模式）**：专门负责虚拟机**访问互联网**。它会借用主机的物理网络上网，你无需关心其 IP，通常由 DHCP 自动分配即可。
*   **网卡二（仅主机模式）**：专门负责**内部网络通信**。你可以把它规划为 `100.110.111.0` 网段，并将虚拟机在该网卡上的 IP 设为 `100.110.111.8`。此模式下的网络完全包含在宿主机内部，适合构建隔离的测试环境。

### 具体操作步骤

**第一步：在 VMware 中配置虚拟网络**
1.  打开 **“编辑”** > **“虚拟网络编辑器”**（可能需要点击“更改设置”获取管理员权限）。
2.  选择 **VMnet1**（通常为仅主机模式）。取消勾选“将主机虚拟适配器连接到此网络”（如果不希望宿主机参与该网络），并**确保已连接**。
3.  配置 **VMnet1** 的子网 IP。例如，设置为 `100.110.111.xxx`，子网掩码 `255.255.255.0`。同时，确保 DHCP 设置（如启用）分配的地址范围也在此网段内，或者你计划稍后在虚拟机内手动设置静态 IP。
4.  确认 **VMnet8**（NAT 模式）保持默认启用状态，它负责上网功能。

**第二步：为虚拟机添加并设置网卡**
1.  关闭虚拟机，进入 **“虚拟机设置”** > **“硬件”** 选项卡。
2.  点击 **“添加”**，选择 **“网络适配器”**，完成添加。
3.  现在你有两块网卡，分别设置：
    *   **网络适配器 1**：选择 **“NAT 模式”**。用于上网。
    *   **网络适配器 2**：选择 **“仅主机模式”**（或“自定义”并选择 VMnet1）。用于你的 `100.110.111.xxx` 网络。

**第三步：在虚拟机操作系统内配置 IP**
启动虚拟机，在操作系统的网络设置中：
*   为 NAT 模式的网卡（通常是 eth0 或 ens***）保留 DHCP 自动获取，或者手动设置一个 DHCP 池内的地址。

#### 查看网络配置 ####

```shell
ifconfig
```

#### 查看 `NetworkManager` 连接 ####

```shell
nmcli connection show
```

#### 查看 `NetworkManager` 托管状态 ####

```shell
nmcli device status
```

*   为仅主机模式的网卡（通常是 eth1 或 ens***）手动设置静态 IP 为 **`100.110.111.***`**，子网掩码 `255.255.255.0`。**不要设置默认网关**，或者确保网关留空/不指向该网卡，否则可能会影响上网流量的路由选择。

这样配置后，你的虚拟机既能通过 NAT 网卡正常上网，又能通过 `100.110.111.8` 这个 IP 与宿主机或其他同网段虚拟机进行内部通信。
